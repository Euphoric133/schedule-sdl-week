# 验收用例与测试映射（ACCEPTANCE）

本文件是"需求 ↔ 测试 ↔ 实现状态"的对照表，用于回答两个问题：

1. 每条需求有没有对应的自动化测试？
2. 现在到底验到了什么程度（哪些是自动化通过、哪些需要人工确认、哪些还没实现）？

**状态图例**

- ✅ **自动化通过**：有测试文件与断言，`node --test "tests/**/*.test.js"` 全绿。
- 🟡 **部分自动化**：核心逻辑已测，但依赖阶段 2/3/4 的部分尚未实现。
- ⏳ **待实现**：功能本身尚未开发（阶段 2–4）。
- 👤 **需人工确认**：涉及真实浏览器渲染与交互，需按"人工验收步骤"操作。

